# U.S. High School Educational Inequality Analysis

---

## Project Overview

This project explores inequality in educational opportunities across U.S. high schools by examining student performance on the ACT and SAT. The main goal is to investigate whether differences in school-level test performance are associated with socioeconomic factors such as income, poverty, demographics, or access to educational resources.

- **Objective:** Educational Opportunity and SAT/ACT Performance in U.S. High School
- **Domain:** Education
- **Key Techniques:** Data cleaning, missing-value imputation, exploratory data analysis, visualization, and statistical testing.
